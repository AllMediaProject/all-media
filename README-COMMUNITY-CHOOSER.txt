ALL MEDIA — COMMUNITY FEED CHOOSER

STEP 1 ONLY:
This package connects the Community button on Home feed cards to the new matching Community chooser.

WHAT IT DOES
- Works on Regular Post, Blog, Video, and Byte cards.
- Shows only Communities you have joined.
- Uses the post Interest + hashtags to recommend relevant Communities.
- Uses saved Community Interests when available.
- Uses the built-in Community Interest sets for the current sample Communities.
- If matches exist, relevant Communities appear first.
- "Show all Communities" reveals the complete joined list.
- If nothing matches, all joined Communities appear automatically.
- The list becomes scrollable as it grows.
- No Create Community button.
- Community choices that explicitly disable reblogs are omitted.
- Selection is visual in this step; ACTUAL SHARING INTO THE COMMUNITY FEED IS NOT CONNECTED YET.

UPLOAD
1. Unzip this package.
2. Rename:
      community-integration.txt
   to:
      community-integration.js
3. Upload it to the root of your all-media GitHub repository.
4. Replace the existing community-integration.js file.
5. Do NOT change index.html.
6. Refresh the live Home page and test Community on all four card types.

Add matching Community feed chooser
