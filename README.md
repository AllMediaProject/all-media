# All Media — Chromebook-Friendly Organized Version

This is the approved V110 Home page separated into ordinary files that can all
be uploaded together with GitHub's file picker.

```text
index.html
all-media.css
all-media.js
all-media-logo.png
README.md
```

Keep all five files together at the published root of the repository. Do not
rename them. No installation, framework, build command, or configuration is
required.

The files have separate responsibilities:

- `index.html` — Home page structure
- `all-media.css` — complete visual design
- `all-media.js` — complete Home-page functionality
- `all-media-logo.png` — brand logo
- `README.md` — these instructions

The original V110 single-file version remains the rollback baseline.
